# Users API — Register Endpoint

Endpoint: `POST /users/register`

Description
- Registers a new user, hashes the password, and returns an auth token and created user object.
- Implementation: [`user.controller.registerUser`](Backend/controllers/user.controller.js)
- Route: [`user.routes`](Backend/routes/user.routes.js)
- Relevant model helpers: [`user.model.hashPassword`](Backend/models/user.model.js), [`user.model.generateAuthToken`](Backend/models/user.model.js)

Request
- URL: `/users/register`
- Method: `POST`
- Headers:
  - `Content-Type: application/json`

Request body (JSON)
- Required shape:
  {
    "fullname": {
      "firstname": "string (min 3 chars)",
      "lastname": "string (optional, min 3 chars)"
    },
    "email": "string (valid email)",
    "password": "string (min 6 chars)"
  }

Validation (from [`user.routes`](Backend/routes/user.routes.js))
- `fullname.firstname`: required, minimum length 3
- `email`: must be a valid email
- `password`: minimum length 6

Example request
{
  "fullname": {
    "firstname": "Alice",
    "lastname": "Smith"
  },
  "email": "alice@example.com",
  "password": "securePass123"
}

Responses

- 201 Created
  - Condition: user successfully registered
  - Body:
    {
      "message": "User registered successfully",
      "token": "<jwt-token>",
      "user": {
        "_id": "...",
        "fullname": { "firstname": "...", "lastname": "..." },
        "email": "..."
        // password is excluded by schema select:false
      }
    }

- 400 Bad Request
  - Condition: validation failed (see rules above)
  - Body:
    {
      "errors": [
        { "msg": "Invalid email", "param": "email", ... },
        ...
      ]
    }

- 500 Internal Server Error
  - Condition: unexpected server error during registration
  - Body:
    {
      "message": "Server error during registration",
      "error": "<error message>"
    }

Notes
- Password hashing is performed by [`user.model.hashPassword`](Backend/models/user.model.js) before creating the user.
- The returned token is generated by [`user.model.generateAuthToken`](Backend/models/user.model.js).
- Register route is mounted under `/users` in [`app.js`](Backend/app.js) — full path becomes `/users/register`.
